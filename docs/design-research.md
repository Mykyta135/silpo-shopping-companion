# Дослідження перед редизайном

Зібрано 2026-08-09, перед переробкою візуалу.

## 1. Фірмові кольори «Сільпо» — виміряні, не вгадані

Сайт і сторінки застосунку закриті Cloudflare, тому кольори взято **з реальних
промо-зображень CDN «Сільпо»** (ті самі, що приходять у купонах через MCP)
шляхом читання пікселів.

| Роль | Значення | Звідки |
| --- | --- | --- |
| **Основний бренд** | `#F86E2C` помаранчевий | фон промо-картки `content.silpo.ua` |
| Світлий нейтральний | `#EAEEF0` | фон продуктових зображень |
| Акцент дій (кнопки) | синій | скріншоти кошика застосунку |
| Плашки знижок | помаранчевий | «−10%», «−30%» у кошику |

> **Головний висновок:** у нашому застосунку основний колір — **зелений**
> (`#1f8a3b`). Це **не колір «Сільпо»**. Для критерію «реалістичність
> інтеграції» варто перейти на помаранчевий `#F86E2C`.

Підтвердження зі скріншотів застосунку: екран «Все склалось!» —
суцільний помаранчевий; кнопки дій у кошику — сині; бейджі знижок —
помаранчеві.

## 2. Застосунок «Сільпо»

- App Store: **4.88** з **107 636** оцінок, версія 6.19.0
- Позиціонування: доставка «Сільпо» + LOKO, самовивіз, готова їжа
- Стиль карток товару: біле тло, фото по центру, назва, вага/об'єм сірим,
  перекреслена стара ціна + помаранчева плашка знижки, синя кнопка кількості

## 3. Чи робив хтось карти для супермаркетів

**Так, і це давня галузь** — але майже всі спроби провалились або лишились
нішевими.

| Продукт | Що робить |
| --- | --- |
| **Walmart App** | пошук товару → номер ряду → жива карта магазину; 4600+ магазинів |
| **Aisle411** | 9000 карт магазинів, партнерство з Walgreens |
| **Mappedin** | B2B-платформа: карти, рівні запасів, полиця, оптимальний маршрут |
| **GroceryGPS** | список за рядами, GPS-визначення магазину |

**Що це означає для нас:**

1. **Ідея карти не нова** — Walmart має її з 2018. Отже подавати як
   винахід не можна.
2. **Але жоден з них не робить того, що ми** — вони показують, *де лежить
   товар*. Ми показуємо, *що взяти і чому*, спираючись на чеки, ціни й купони.
   Карта в нас — спосіб упорядкувати список, а не самоціль.
3. **Головна причина провалів** — планограми змінюються постійно, і
   підтримувати точні карти дорого. Саме тому наш підхід (зони за
   галузевим стандартом, чесно позначені як модель) практичніший за
   спробу вдавати точну навігацію.

## Рішення для редизайну

1. **Перейти на помаранчевий `#F86E2C`** як основний — це колір «Сільпо».
   Зелений лишити хіба для станів успіху.
2. **Синій для дій** (кнопки «додати», «оформити») — як у застосунку.
3. **Знижки — помаранчева плашка** з перекресленою старою ціною, як у них.
4. **Картку товару наблизити** до їхньої: фото, назва, вага сірим, ціна жирним.
5. **Карту лишити схематичною** — вона впорядковує список, а не навігує.
