## П'ять фактів, що визначають усе

**1. Конкурент уже в продакшені.** «Машрум Геннадійович» вміє меню, рецепти,
кошик, читання чеків, профіль з чеків, прогноз покупок, дешевші аналоги
і гейміфікацію. Будувати те саме — програш.

**2. Профіль порожній, чеки — ні.** `get_my_family`,
`get_my_food_restrictions`, `get_my_favorites` порожні, онлайн-замовлень нуль.
Єдине джерело правди — **офлайн-чеки**, і в них поруч лежить поточна ціна
каталогу.

**3. Аналітика — не агент.** Критерій 3 вимагає послідовності дій через tools.
Інсайт мусить бути **тригером ланцюжка**, а не фінальним екраном.

**4. Магазин спроєктований проти покупця.** «Змусити покупця максимально довго
перебувати в залі» — галузевий стандарт. Це наша точка опори.

**5. Люди діють навмання.** Гість активував 3 промо (Lion, круасани, соки),
яких немає в жодному його чеку. Не через лінь — через перевантажений інтерфейс.

## Ключова теза

> Магазин спроєктований, щоб ти ходив довше.
> Цей агент — щоб ти пройшов один раз і не забув те, за що тобі платять бонусами.
