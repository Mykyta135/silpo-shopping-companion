## Шість критеріїв оцінювання

1. **Цінність для Гостя або бізнесу** — важливість проблеми та потенційний ефект
2. **Якість використання MCP** — обґрунтованість застосування tools і даних
3. **Агентність рішення** — робота з контекстом, використання інструментів,
   **виконання послідовності дій**
4. **Реалістичність інтеграції** — можливість впровадження в продукт
5. **Прототип і демонстрація** — переконливість показу
6. **Валідація та масштабування** — якість перевірки гіпотези та план розвитку

## Обов'язкові вимоги

- Підключення до `https://mcp.silpo.ua/mcp`
- Виклик щонайменше одного tool з `tools/list` у робочому сценарії
- Робочий прототип або демо, що показує цей виклик
- **Токени зберігаються серверно, а не в клієнтському коді**
- Агентний сценарій, чітка проблема та цільова аудиторія

## Що НЕ приймається

- Проєкти без офіційного MCP
- Загальні AI-ідеї без сценарію
- **FAQ-боти без використання tools**
- Проєкти без чіткої проблеми або цінності

## Найважливіший висновок для нас

Критерій 3 прямо вимагає **послідовності дій**, а не «текстової генерації».

> Аналітика (ціни, купони, витрати) сама по собі — **не агент**.
> Вона мусить бути **тригером ланцюжка**, що закінчується реальною дією
> через tools: заміна позицій → наповнення кошика → застосування купона →
> checkout-посилання.

Це єдиний критерій, де наша аналітична ідея слабка. Все проєктування має
йти від нього.
